# Detail panel removal

Outside a thread, Shell renders neither the right panel nor its toggle, ignores its shortcut and saved-open preference, and reserves zero panel width. The thread context frame, focus return, optional panel controls, pane preferences, separators and all eight thread width-budget cases remain. The centre still keeps 520 px before Line stacks and the sidebar moves off-canvas.

The Releases whole-sweep caveat uses `openEvidence(null)`; `showWholeSweep` takes an existing Evidence route. R14-2 permits only its two obsolete panel assertions to change: they now prove whole-sweep Evidence from Releases. All other `views/*`, Today and `components/evidence` tests are unchanged. Panel Evidence cases in Shell and Settings now assert the Evidence page. The Settings focus opener uses the sidebar toggle with every existing focus assertion retained (R14-4).

`bridgeOpens`, the desktop bridge helper and the complete 25-URL parity table were compared with the base: implementation and table are byte-identical. The parity test moved from `panels/detail-kinds.test.tsx` to `app/external-links.test.ts`.

Text-rule and reachability helpers pin UTC and the recorded morning at file load, before expected clock strings are built, and reinstate that clock for each test. The two-zone briefing test retains every place assertion and drops only Inspector time assertions.

Packaged smoke surfaces `detail` and `detail-related` are now `upstream-item` and `upstream-theme`; their popover coverage remains. Window geometry rejects any right panel or panel toggle, the pinned-Line probe expects three panes, and the top-row pin stays at the centre end. The palette Escape-while-popover-open analogue belongs to the sweep bead and is not added here.
